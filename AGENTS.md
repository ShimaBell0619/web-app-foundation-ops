# Operations repository rules

The canonical shared rules are [Foundation AGENTS.md](https://github.com/ShimaBell0619/web-app-foundation/blob/84477e463d60d460fe8683921b7402e336149798/AGENTS.md). Preserve Chat-first and use Work only on an explicit user request.

Follow the activation gate and operation scope in README.md. Code changes use a branch, PR, final-head CI and self-review. Never weaken protection or save a creation token while main protection is unenforced. Secret values must never be shown or written to Chat, source, Issues, PRs, logs or screenshots. Independent review of the privileged workflow remains required before activation; do not request `@codex review` without per-run human authorization.
